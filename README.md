# 📊 Meridian Dashboard — Admin Dashboard Web Application
**Meridian Dashboard** is a modern, responsive admin dashboard built with **React** and **Tailwind CSS**. It provides a clean interface for monitoring analytics, managing customers, tracking transactions, viewing revenue reports, and configuring application settings.
## ✨ Key Features
- 📈 Interactive analytics dashboard with revenue and visitor charts.
- 💳 Transaction management with recent transactions and detailed transaction tables.
- 👥 Customer management interface.
- 🔔 Notifications panel for important updates.
- 🛡️ Security and workspace settings.
- 📊 Monthly revenue, weekly visitors, and traffic source visualizations.
- 🧭 Responsive sidebar and navigation system.
- 📱 Fully responsive design for desktop, tablet, and mobile devices.
## 🛠 Tech Stack
**Frontend:** React, JavaScript (ES6+), HTML5, Tailwind CSS
**Routing:** React Router DOM
**Charts:** Recharts
**Icons:** Lucide React
**Build Tool:** Vite
**Version Control:** Git & GitHub

## ⚙️ Installation & Setup
### Prerequisites
Ensure you have the following installed:
- Node.js (v16 or higher)
- npm
### Clone the Repository
```bash
git clone https://github.com/izwairfan06-star/Meridian_Dashboard.git
```
### Navigate to the Project
```bash
cd Meridian_Dashboard
```
### Install Dependencies
```bash
npm install
```
### Start the Development Server
```bash
npm run dev
```
### Open in Browser
```
http://localhost:5173
```
